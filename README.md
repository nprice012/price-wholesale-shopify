# Price Wholesale Distribution — Shopify Theme

Custom Shopify Online Store 2.0 theme for Price Wholesale Distribution.

## Current direction

- Family-owned since 1921
- Baltimore & Washington wholesale distributor
- Ice cream, beverages, snacks and foodservice
- Public company/brand information
- B2B customer login and private wholesale pricing
- One wholesale catalog / price level
- Online ordering through Shopify
- Responsive desktop and mobile design

## Hero image

The homepage hero is intentionally configured as a Shopify Theme Editor image setting. Upload the approved Price Distribution banner and select it under **Homepage hero banner → Hero banner image**.

## B2B behavior

The theme uses Shopify's `customer.b2b?` Liquid property to keep prices, add-to-order controls and cart/checkout content restricted to verified B2B customers.

Product data and product photography should remain in Shopify rather than being hard-coded into the theme. This keeps the catalog maintainable as the product list grows.
